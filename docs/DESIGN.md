# QuickVerse Vendor — design system

Blue & white, Apple-minimal, built for a busy shop counter: the phone is read from arm's length, often mid-rush, by
staff who may read little English. So: big type, one main action per card, every status as an icon **and** a word.

## Tokens (`src/ui/theme.ts`)
| Token | Hex | Use |
|---|---|---|
| bg | #F3F5F9 | screen background (grouped) |
| surface | #FFFFFF | cards, lists, sheets |
| ink / ink2 / ink3 | #0B1B34 / #55647A / #8B97A9 | text: primary / secondary / hints |
| line | #E3E8F0 | hairlines (no shadows anywhere) |
| blue (+pressed, soft, soft pressed) | #1557FF (#0E43CC, #EAF0FF, #D9E4FF) | brand, primary actions, new orders |
| green (+pressed, soft) | #0B7F58 (#086246, #E6F5EE) | online, ready, delivered |
| red (+pressed, soft) | #D42A33 (#B0222A, #FDECEC) | late, reject, offline |
| amber (+soft) | #A85F00 (#FFF3DE) | preparing, warnings |
| track | #E8ECF3 | segmented-control background |

Spacing 4/8/12/16/24/32 · radius 10/14/20/28/pill (buttons & chips 14, cards 20, sheets 28).

## Type — Plus Jakarta Sans (OFL)
| Variant | Size/line | Weight |
|---|---|---|
| display | 40/46 | Bold (tabular for money/timers) |
| largeTitle | 30/36 | Bold |
| title | 20/26 | SemiBold |
| headline | 17/22 | SemiBold |
| body | 15/21 | Regular |
| callout | 14/19 | Medium |
| footnote | 13/18 | Regular |
| caption | 12/16 | Medium |

Always render text with `<Txt variant>`; Android picks the weight by font file name, so never set `fontWeight`.

## Components (`src/ui/`)
Txt · Icon (Lucide glyphs) · Button (primary / secondary / danger / success / ghost; l 56 dp, m 48, s 36; `pulse`) ·
Sheet (bottom sheet) · Segmented · Chip · StatusPill · Group/Row (iOS-Settings lists) · EmptyState · LargeHeader.

## Principles
1. The boldness lives in one place: the incoming-order card's blue header band with its ticking timer.
2. Every state is an icon plus a word (Live, Rider at your shop), never color alone.
3. One primary action per card, full width, 56 dp.
4. Motion only for attention or response (new-order pulse, late "food ready" pulse, sheets); off with reduce-motion.
5. Copy: sentence case, plain verbs ("Accept order", "Mark food ready", "Hand over to rider").

## Fonts and icons
Bundled in `android/app/src/main/assets/fonts/`, generated by `scripts/make-fonts.py`:
```bash
npm pack lucide-static && tar -xzf lucide-static-*.tgz          # icons (ISC)
curl -LO "https://github.com/google/fonts/raw/main/ofl/plusjakartasans/PlusJakartaSans%5Bwght%5D.ttf"
python scripts/make-fonts.py package "PlusJakartaSans[wght].ttf"  # needs: pip install fonttools
```
To add an icon, append its Lucide name to `ICON_NAMES` in the script and re-run it (rewrites `src/ui/iconMap.ts`).
