Wave: 0 · Deps: none · Risk: low · Model: orchestrator · Oracle: none

## Goal
`QVIcons.ttf` and `src/ui/iconMap.ts` contain the four new Lucide glyphs `search`, `calendar`, `chevron-down`,
`hourglass` next to every existing icon, so later tasks can draw them with `<Icon name="search" />` and the like.

## Context
The app draws icons from a bundled subset of the Lucide icon font (scripts/make-fonts.py). Adding an icon = append
its name to `ICON_NAMES` and rebuild only the icon font (the four Plus Jakarta Sans text fonts must not change).
Done by the orchestrator in the main session because it needs the `lucide-static` npm tarball (a download).
