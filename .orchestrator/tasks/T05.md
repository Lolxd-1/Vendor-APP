# T05: History redesign (search, period, day groups, clean rows)
Wave: 5 · Deps: T02 T03 · Risk: med · Model: sonnet · Oracle: fail-before

## Goal
Rebuild `HistoryScreen` to industry standard: search box, one filter row (period button + status chips), orders
grouped by day under sticky headers with totals, rows whose text never wraps or collides, paging, skeleton, empty and
error states. Tapping a row calls `onOpenOrder(order)`; the old bill sheet is deleted.

## Context
M1. The owner reported "text or alignment issues" and asked for best practices: search, date grouping with sticky
headers, a single compact filter row, skeleton loading, clear empty/error states, amounts right-aligned in tabular
digits. Data: `getOrdersPage` (T02); periods: `src/domain/period.ts` (T01); picker: `PeriodSheet` + `SearchField` (T03).
The details page itself is T04 and is opened by MainShell (T07) through `onOpenOrder`.

## Steps
1. State: `period` (initial `presetPeriod('TODAY', new Date())`), `status` (same STATUSES table as today: All [] /
   Delivered COMPLETED / On the way IN_TRANSIT / Rejected REJECTED / Cancelled CANCELLED), `query` (search text),
   list {orders, page, totalPages, totalElements?}, loading 'first' | 'more' | 'refresh' | null, error, sheet open.
2. Loading: `getOrdersPage(shopId, { statuses: status.statuses, ...queryOf(period), page })` — keep the request-id
   guard so only the newest request writes; page 0 replaces, later pages merge with `mergeOrders`. Reload page 0 when
   period or status changes. Infinite scroll (`onEndReached`, threshold 0.4) while page + 1 < totalPages, not loading,
   no error. Pull-to-refresh reloads page 0.
3. Header: `LargeHeader title="History"`, subtitle: totalElements known -> `${n} orders` ('1 order'); else loaded
   count with '+' when more pages; before the first answer 'Your past orders'.
4. Under it: `SearchField placeholder="Search order ID or customer"`; then one horizontal ScrollView
   (`style={{ flexGrow: 0 }}`, gap `space.s`, padding 16) holding the period button first — a Pressable chip with
   `Icon calendar`, `period.label`, `Icon chevron-down`, `accessibilityLabel={`Period: ${period.label}`}` that opens
   `PeriodSheet` (`now={new Date()}`; onChange sets period) — followed by the five status Chips.
5. Search: trimmed lower-case query; an order matches when `orderId` or `customerName` contains it. Only loaded orders
   are searched.
6. List: `SectionList` with `stickySectionHeadersEnabled`. Group the (filtered) orders by local day of
   `parseServerTime(creationTime)` in server order: title 'Today', 'Yesterday', otherwise `dayLabel(day)`; orders whose
   time is unreadable form a last section 'Earlier'. Section header (bg `colors.bg`, paddingVertical `space.s`):
   title `Txt headline` left; right `Txt footnote ink2`: `${n} order(s)` plus ` · ${money(sum)} delivered` when the sum of
   `amountExcludingDeliveryFee` over COMPLETED orders in the section is > 0.
7. Row (white card, radius `radius.l`, hairline border, padding `space.l`, gap 4; Pressable with
   `accessibilityLabel={`Order ${id}, ${status.label}, ${amount}`}` -> `onOpenOrder(order)`):
   - line 1: `#${orderId}` (headline, `flex: 1, minWidth: 0`, numberOfLines 1) | amount (headline, tabular,
     `flexShrink: 0`; color ink3 for REJECTED and CANCELLED, ink otherwise)
   - line 2: `${clockTime(creationTime)}` + ` · ${customerName}` when present (footnote ink2, `flex: 1, minWidth: 0`,
     numberOfLines 1) | `StatusPill` (`flexShrink: 0`)
   - line 3: `itemsSummary(orderItem)` (footnote ink2, numberOfLines 1)
8. States: first load -> 4 skeleton cards (static grey blocks, `accessibilityLabel="Loading orders"`); error with no
   orders -> `EmptyState icon wifi-off title "Couldn't load orders" body=error action "Try again"` (reload page 0);
   no orders -> `EmptyState icon inbox "No orders in this period" body "Try a longer time range."`; search with no
   matches -> `EmptyState icon search title={`No orders match "${query.trim()}"`}`, and when more pages exist a
   `Button "Search older orders"` that loads the next page; footer: spinner while loading more, or error text +
   `Button "Try again"` (loads the failed page) when a later page failed.
9. Delete `src/components/OrderDetailsSheet.tsx` (only this screen imported it).
10. In `src/app/MainShell.tsx` change only the History entry of the tabs map to
    `history: <HistoryScreen shopId={session.shopId} onOpenOrder={() => undefined} />` (ruling: T07 replaces it with
    the real order page in this run). No other line of MainShell may change.
