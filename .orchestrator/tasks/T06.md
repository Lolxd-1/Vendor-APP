# T06: Earnings screen (weekly payout + order-wise cards)
Wave: 6 · Deps: T00 T01 T02 · Risk: med · Model: sonnet · Oracle: fail-before

## Goal
A new Earnings screen like Zomato's Payouts: the settlement week (Mon–Sun, paid the next Monday) with its totals, and
every delivered order as a card (Delivered + Settled/To be paid pills, ID, date · payment, Gross revenue, Commission,
Net receivable, Details).

## Context
M1. Rules from T01 (`settlementWeek`, `rangeQuery`, `rangeLabel`, `dayLabel`, `payoutOf`, `summarize`); data from
`getAllOrders` (T02) — only COMPLETED orders of one week, at most 20 pages, loaded on mount, on week change, when the tab
becomes active again, and on pull-to-refresh; never on a timer (production backend). The owner's screenshot (Zomato
Payouts > Orders) shows per card: DELIVERED and TO BE PAID pills, "ID: 8704815438", "Details ›", "09 Oct'26 7:38 PM •
Paid online", Gross revenue, Net receivable. MainShell (T07) mounts this as the Earnings tab.

## Contracts
- Consumes: `getAllOrders(shopId, f, maxPages?)` (T02); `settlementWeek`, `rangeQuery`, `rangeLabel`, `dayLabel`, `payoutOf`, `summarize`, `DEFAULT_COMMISSION_PCT` (T01)
- Produces: `export const EarningsScreen: (p: { shopId: string; active: boolean; onOpenOrder: (o: Order) => void }) => JSX.Element`

## Steps
1. State `offset` (0 = current week, ≤ 0). week = `settlementWeek(new Date(), offset)`.
   `useRemote(() => getAllOrders(shopId, { statuses: ['COMPLETED'], ...rangeQuery(week) }), [shopId, offset])`;
   reload when `active` turns true again (InsightsScreen pattern); `RefreshControl` calls reload.
2. Header: `LargeHeader title="Earnings"`. Week bar: Pressable `accessibilityLabel="Previous week"` (chevron-left),
   centre title ('This week' when offset 0, 'Last week' when -1, else `rangeLabel(week)`) with `rangeLabel(week)` under
   it (when the title is not already the range), Pressable `accessibilityLabel="Next week"` (chevron-right) disabled
   (`accessibilityState.disabled`, 0.35 opacity) when offset is 0.
3. Summary card (white, radius `radius.l`): caption 'Net receivable', `Txt display tabular` `money(sum.net)`,
   footnote `Payout on ${dayLabel(week.end)} · ${n} order(s)`; rows 'Gross revenue' `money(sum.gross)`, 'Commission'
   `money(-sum.commission)`, 'To be paid' `money(sum.toBePaid)` (amber), 'Settled' `money(sum.settled)` (green);
   when `sum.estimated`: info row 'Commission is estimated at 10% where QuickVerse did not send it.'; when
   `complete === false`: 'Showing the first 1,000 orders of this week'.
4. Section title 'Orders' then one card per order with a payout (server order). Card = Pressable,
   `accessibilityLabel={`Order ${id}, net receivable ${money(p.net)}`}` -> `onOpenOrder(order)`:
   row 1: pills 'Delivered' (green, circle-check) and 'Settled' (green, badge-check) or 'To be paid' (amber,
   hourglass), right 'Details' (callout, blue) + chevron-right; row 2: `ID: ${orderId}` (headline, 1 line);
   row 3: icon calendar + `${dayTime(creationTime, Date.now())} · ${paymentLabel(paymentMethod)}` (footnote ink2,
   1 line); hairline; lines 'Gross revenue' `money(p.gross)`, `Commission (${p.pct}%${p.estimated ? ', estimated' : ''})`
   `money(-p.commission)`, 'Net receivable' `money(p.net)` (headline). Values tabular, `flexShrink: 0`.
5. States: first load (no data) -> ActivityIndicator; error with no data -> `EmptyState icon wifi-off title "Couldn't
   load earnings" body=error action "Try again"`; error with data -> keep data and show the error line under the
   summary; no orders -> `EmptyState icon wallet title "No delivered orders in this week"`.
