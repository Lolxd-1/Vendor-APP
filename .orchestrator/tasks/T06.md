## Steps
1. LargeHeader 'History'. Two horizontal chip rows: time Today/This week/This month → TODAY/LAST_WEEK/THIS_MONTH
   (default TODAY); status All/Delivered/On the way/Rejected/Cancelled → []/['COMPLETED']/['IN_TRANSIT']/['REJECTED']/['CANCELLED'].
2. Filter change → reset list, load page 0 (a request id ignores stale responses). onEndReached → next page while
   page + 1 < totalPages and not loading; `mergeOrders` appends. Pull-to-refresh reloads page 0.
3. Row (white card radius l): left '#<orderId>' headline + dayTime(creationTime) footnote + itemsSummary (1 line);
   right money(amountExcludingDeliveryFee) + StatusPill(historyStatusInfo(state)). Press → OrderDetailsSheet.
4. OrderDetailsSheet: status pill, '#id', dayTime; customer name + payment label; items with qty/price; bill rows
   'Items total' (amountExcludingDeliveryFee), 'Delivery fee' (when number), 'Customer paid' (totalAmount when number);
   instructions; rider name + phone Call button when present.
5. States: first load spinner; empty EmptyState inbox 'No orders in this period' / 'Try a longer time range.';
   error EmptyState wifi-off with the error text and action 'Try again'; footer spinner while loading more.
6. MainShell: render HistoryScreen for tab 'history' (shopId from session).

## Test cases
- TC1 initial load calls getOrdersPage('7',{statuses:[],timeRange:'TODAY',page:0}) and shows '#A1' and 'Delivered'.
- TC2 press 'Rejected' chip → getOrdersPage called with statuses ['REJECTED'], page 0.
- TC3 empty result → 'No orders in this period'.
- TC4 rejection → error text + 'Try again' → retried (called again).
- TC5 press a row → sheet shows 'Items total'.
