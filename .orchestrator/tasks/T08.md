## Steps
1. AccountScreen props `{ session, profile, setup, onOpen(page) }`: header card — 64 dp logo (Image uri when
   profile.logo starts with http, else blue circle with initials), name (title) or 'Shop #id', category footnote,
   'Shop #<id>'. Group 'Store': 'Store timings' (calendar-clock) → onOpen('timings'); 'Order alerts & phone setup'
   (bell-ring) → onOpen('alerts') with red 'Fix needed' value when any setup check is false; 'Test order sound'
   (volume-2) → playTestSound + ToastAndroid 'Playing test sound'. Group 'Shop details' (only rows with data): Owner
   (user-round), Phone (phone, press → tel:), Address (map-pin, joined address/city/state/postalCode), Usual hours
   (clock, 'openingTime – closingTime'). Group 'App': 'Signed in as +91 <phone>' (smartphone), 'Version 1.0.0' (info).
   Last: danger row 'Log out' (log-out) → Alert.alert('Log out?', 'New orders will NOT ring on this phone until you log in again.', Cancel / destructive 'Log out' → logout).
2. StoreTimingsScreen props `{ store, onBack }`: LargeHeader 'Store timings' with back; intro 'Set when your store is
   closed. Outside these hours, customers can order.'; manual-offline note when schedule.manualOffline; Group of 7
   rows dayName + slotLabel, today marked 'Today'; press → Sheet editing that day: 3 option rows 'Open all day' /
   'Closed all day' / 'Closed for some hours'; for the last, two steppers 'Closed from' and 'Open again at' (minus/plus
   = shiftHHMM ±30, label hhmmLabel; default 14:00–16:00); primary 'Save' → store.save(nextWeek) (Open all day = delete
   the key; Closed all day = 00:00/00:00) → close sheet + ToastAndroid 'Store timings saved'; failure keeps sheet open
   and shows store.error. Loading/error states with 'Try again' (store.reload).
3. AlertsScreen props `{ board, setup, onBack }`: LargeHeader 'Order alerts' with back; status card: connection pill +
   'Last checked <n> s ago' (from board.lastPollAt, ticking each 5 s) or 'Not checked yet'; text 'New orders ring loudly,
   even on Silent, until you accept or reject them.'; Group 'Phone setup' 3 rows (Notifications / Full-screen alerts /
   Battery: Unrestricted) each with green check 'On' or blue 'Fix' button → openSetting(kind); primary 'Play test sound';
   Group 'Xiaomi, Oppo, Vivo, Realme' footer text 'Also turn on Autostart for QuickVerse Vendor in App info.' with row
   'Open App info' → openSetting('appDetails').
4. MainShell: tab 'account' → AccountScreen; stack top 'timings'/'alerts' renders that page over the tabs (tab bar
   hidden while a page is open); Orders' onOpenAlerts and StoreSwitch's open-timings push pages.
