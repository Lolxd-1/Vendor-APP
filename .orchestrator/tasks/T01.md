## Steps
1. `scripts/make-fonts.py <lucide-static dir> <PlusJakartaSans[wght].ttf>`: instance wght 400/500/600/700 →
   `PlusJakartaSans-{Regular,Medium,SemiBold,Bold}.ttf` (fontTools.varLib.instancer; name IDs 1/4/6 = file stem);
   subset Lucide `font/lucide.ttf` to ICON_NAMES (codepoints from `font/codepoints.json`) → `QVIcons.ttf`; write
   `src/ui/iconMap.ts` (`export const ICONS = {...} as const`, values `'\uXXXX'`). Exit 1 if any name is missing.
2. ICON_NAMES: receipt-text, history, chart-column, store, phone, bike, clock, timer, chef-hat, package-check, check,
   circle-check, x, chevron-right, chevron-left, minus, plus, bell, bell-ring, volume-2, wifi, wifi-off, log-out,
   calendar-clock, info, triangle-alert, map-pin, user-round, shield-check, battery-charging, smartphone, refresh-cw,
   inbox, ban, circle-x, power, settings, wallet, utensils, key-round, hand-platter, indian-rupee, trending-up, hash,
   message-square-text, badge-check.
3. theme.ts tokens exactly as PLAN; Txt applies `type[variant]` + color + optional tabular-nums; Icon = Text with
   fontFamily 'QVIcons', `allowFontScaling={false}`, hidden from accessibility.
4. Button variants: primary (blue fill), secondary (blueSoft fill, blue text), danger (red fill), success (green fill),
   ghost (no fill, blue text); size l=56, m=48, s=36 dp; busy → ActivityIndicator; disabled → 40% opacity;
   pressed → darker + scale 0.98; `pulse` → looping opacity 1↔0.7 (off when reduced motion).
5. Sheet: Modal transparent, backdrop `scrim` fades, panel slides from bottom (Animated, 220 ms), radius xl top,
   grab handle, optional title, `onRequestClose` = onClose, bottom padding for the gesture bar.
6. Segmented: grey track, white selected thumb, label + count bubble (red when `alert`), roles tablist/tab.
7. List Group/Row like iOS Settings: white rounded group (radius l), hairline separators inset 56, icon in a soft-tinted
   rounded square, title/subtitle, right value or node, chevron, `danger` → red title.
8. EmptyState, LargeHeader (largeTitle, optional back button, right slot), Chip (selected = blue fill white text, else
   surface + hairline), StatusPill (soft tone bg + tone text + icon).
9. docs/DESIGN.md: tokens, type scale, components, how to add an icon.

## Test cases
- TC1: `<Txt variant="title">Hi</Txt>` renders "Hi" with fontFamily 'PlusJakartaSans-SemiBold'.
- TC2: `<Icon name="phone"/>` renders ICONS.phone with fontFamily 'QVIcons'.
- TC3: Button onPress fires; with `disabled` or `busy` it does not; busy shows ActivityIndicator.
- TC4: Segmented shows "New" and count "2"; pressing "Ready" calls onChange('READY_FOR_PICKUP').
- TC5: Row onPress fires; EmptyState action fires.
- TC6: Sheet visible=false renders no children; visible=true renders title and children.
