## Contracts
- Produces (copy exactly):
```ts
// order.ts (additive)
export interface OrderFinance { commission?: number; commissionRate?: number }
// Order gains: finance?: OrderFinance | null; completedDate?: string | null; rejectedDate?: string | null; isSettled?: boolean;
export type TimeRange = 'TODAY' | 'LAST_WEEK' | 'THIS_MONTH' | 'THIS_YEAR' | 'CUSTOM';
// period.ts
export interface Range { start: Date; end: Date }   // half-open [start, end)
export type PresetKey = 'TODAY' | 'YESTERDAY' | 'LAST_7_DAYS' | 'THIS_MONTH' | 'LAST_MONTH';
export const PRESETS: readonly { key: PresetKey; label: string }[];
export interface Period { key: PresetKey | 'CUSTOM'; label: string; range: Range }
export const startOfDay: (d: Date) => Date;
export const addDays: (d: Date, days: number) => Date;
export const presetPeriod: (key: PresetKey, now: Date) => Period;
export const customPeriod: (a: Date, b: Date) => Period;
export const settlementWeek: (now: Date, offset: number) => Range;
export const toBackendTime: (d: Date) => string;
export interface OrdersQuery { timeRange: TimeRange; fromTime?: string; toTime?: string }
export const queryOf: (p: Period) => OrdersQuery;
export const rangeQuery: (r: Range) => OrdersQuery;
export const dayLabel: (d: Date) => string;
export const rangeLabel: (r: Range) => string;
// payout.ts
export const DEFAULT_COMMISSION_PCT = 10;
export interface Payout { gross: number; commission: number; net: number; pct: number; estimated: boolean; settled: boolean }
export const commissionAt: (gross: number, pct: number) => number;
export const payoutOf: (o: Order) => Payout | null;
export interface PayoutSummary { orders: number; gross: number; commission: number; net: number; settled: number; toBePaid: number; estimated: boolean }
export const summarize: (orders: Order[]) => PayoutSummary;
// timeline.ts
export type StepKey = 'placed' | 'accepted' | 'ready' | 'onTheWay' | 'delivered' | 'rejected' | 'cancelled';
export interface Step { key: StepKey; title: string; at: number | null; done: boolean; detail: string | null; tone: 'neutral' | 'green' | 'red' }
export const timelineOf: (o: Order) => Step[];
```

## Steps
1. order.ts: add `OrderFinance`, the four optional `Order` fields, and `'CUSTOM'` to `TimeRange`.
2. period.ts rules:
   - `PRESETS` in order: TODAY 'Today', YESTERDAY 'Yesterday', LAST_7_DAYS 'Last 7 days', THIS_MONTH 'This month', LAST_MONTH 'Last month'.
   - `presetPeriod`: with t = startOfDay(now): TODAY [t, t+1d); YESTERDAY [t−1d, t); LAST_7_DAYS [t−6d, t+1d);
     THIS_MONTH [1st of now's month, 1st of next month); LAST_MONTH [1st of previous month, 1st of now's month). Label from PRESETS.
   - `customPeriod(a, b)`: lo/hi = earlier/later of startOfDay(a), startOfDay(b); range [lo, hi+1d); key 'CUSTOM'; label = rangeLabel(range).
   - `settlementWeek(now, offset)`: start = startOfDay(now) moved back to its Monday (Sunday belongs to the week that began the Monday before), then + offset × 7 days; end = start + 7 days.
   - `toBackendTime`: zero-padded local `YYYY-MM-DDTHH:mm:ss`.
   - `queryOf`: key TODAY -> `{ timeRange: 'TODAY' }`; THIS_MONTH -> `{ timeRange: 'THIS_MONTH' }`; otherwise `rangeQuery(p.range)`.
   - `rangeQuery`: `{ timeRange: 'CUSTOM', fromTime: toBackendTime(start), toTime: toBackendTime(new Date(end.getTime() - 1000)) }`.
   - `dayLabel`: 'Mon, 19 Oct' (3-letter weekday, day, 3-letter month).
   - `rangeLabel`: last = startOfDay(new Date(end.getTime() − 1)); same day -> '6 Oct'; same year -> '12 Oct – 18 Oct'; years differ -> '29 Dec 2025 – 4 Jan 2026'. The dash is ' – ' (en dash with spaces).
   - Use `new Date(y, m, d)` arithmetic (calendar days), never `+ 86400000` (keeps midnight exact).
3. payout.ts rules:
   - `commissionAt(gross, pct) = Math.round(Math.round(gross * 100) * pct / 100) / 100`.
   - `payoutOf`: return null unless `String(o.state).trim().toUpperCase() === 'COMPLETED'` and gross =
     `o.amountExcludingDeliveryFee` is a finite number ≥ 0. If `o.finance?.commission` is a finite number with
     0 ≤ c ≤ gross: commission = round2(c), pct = gross > 0 ? Math.round(c / gross * 1000) / 10 : 0, estimated false.
     Else commission = commissionAt(gross, DEFAULT_COMMISSION_PCT), pct = 10, estimated true.
     net = round2(gross − commission); settled = `o.isSettled === true`. round2(x) = Math.round(x * 100) / 100.
   - `summarize`: over orders whose payoutOf is not null: orders = count; gross, commission, net = round2 sums;
     settled = round2 Σ net of settled; toBePaid = round2 Σ net of not settled; estimated = any estimated.
4. timeline.ts rules (s = upper-cased trimmed state; times via parseServerTime):
   - placed = { 'Order placed', at: creationTime, done: true, detail: null, tone: 'neutral' } — always first.
   - REJECTED: [placed, { 'rejected', 'Rejected', at: rejectedDate, done: true, detail: null, tone: 'red' }].
   - CANCELLED: [placed, accepted (only if acceptedDate parses), ready (only if readyDate parses),
     { 'cancelled', 'Cancelled', at: null, done: true, detail: null, tone: 'red' }].
   - Otherwise: [placed, accepted, ready, onTheWay (only when s === 'IN_TRANSIT'), delivered].
     accepted = { 'Accepted', at: acceptedDate, done: at !== null || s in ACCEPTED/READY_FOR_PICKUP/IN_TRANSIT/COMPLETED,
       detail: both times known and diff > 0 ? `Took ${minutesLabel(sec)} to accept` : null, tone: 'neutral' }.
     ready = { 'Food ready', at: readyDate, done: at !== null || s in READY_FOR_PICKUP/IN_TRANSIT/COMPLETED }; with
       prep = ready − accepted seconds (> 0) and promised = `preparationTime` minutes (> 0):
       late = Math.floor((prep − promised × 60) / 60); late ≥ 1 -> detail `Cooked in ${minutesLabel(prep)} · ${late} min late`, tone 'red';
       else `Cooked in ${minutesLabel(prep)} · on time`, tone 'green'; prep known but no promise -> `Cooked in ${minutesLabel(prep)}`, 'neutral';
       prep unknown -> detail null, 'neutral'.
     onTheWay = { 'Picked up by the rider', at: null, done: true, detail: null, tone: 'neutral' }.
     delivered = { 'Delivered', at: completedDate, done: s === 'COMPLETED', detail: null, tone: done ? 'green' : 'neutral' }.
   - Never throws on missing or broken fields.

## Test cases
Dates are local: `new Date(2026, 9, 14, 15, 30)` is Wed 14 Oct 2026 (12 Oct 2026 is a Monday).
- TC1 `test: presets give half-open local ranges`: now Wed 14 Oct 15:30 -> TODAY [14 Oct, 15 Oct), YESTERDAY [13, 14), LAST_7_DAYS [8 Oct, 15 Oct), THIS_MONTH [1 Oct, 1 Nov), LAST_MONTH [1 Sep, 1 Oct); labels as in PRESETS
- TC2 `test: custom range covers whole days and swaps reversed picks`: customPeriod(9 Oct 18:00, 6 Oct 08:00) -> key CUSTOM, [6 Oct 00:00, 10 Oct 00:00), label '6 Oct – 9 Oct'; customPeriod(6 Oct, 6 Oct) -> [6 Oct, 7 Oct), label '6 Oct'
- TC3 `test: backend times are local and zero padded`: toBackendTime(new Date(2026, 0, 5, 7, 8, 9)) -> '2026-01-05T07:08:09'
- TC4 `test: queryOf uses presets for Today and This month and CUSTOM otherwise`: TODAY -> { timeRange: 'TODAY' }; THIS_MONTH -> { timeRange: 'THIS_MONTH' }; YESTERDAY (now 14 Oct) -> { timeRange: 'CUSTOM', fromTime: '2026-10-13T00:00:00', toTime: '2026-10-13T23:59:59' }
- TC5 `test: settlement week edges`: settlementWeek(Sun 18 Oct 23:59, 0) -> [Mon 12 Oct, Mon 19 Oct); (Mon 19 Oct 00:00, 0) -> [19 Oct, 26 Oct); (Wed 14 Oct, -1) -> [5 Oct, 12 Oct)
- TC6 `test: labels`: dayLabel(19 Oct 2026) 'Mon, 19 Oct'; rangeLabel([12 Oct, 19 Oct)) '12 Oct – 18 Oct'; rangeLabel([6 Oct, 7 Oct)) '6 Oct'; rangeLabel([29 Dec 2025, 5 Jan 2026)) '29 Dec 2025 – 4 Jan 2026'
- TC7 `test: estimated 10 percent when the backend sends no commission`: {state:'COMPLETED', amountExcludingDeliveryFee:245} -> { gross:245, commission:24.5, net:220.5, pct:10, estimated:true, settled:false }

- TC9 `test: uses the backend commission when it is sent`: amount 200, finance {commission:16}, isSettled true -> commission 16, pct 8, estimated false, net 184, settled true

- TC11 `test: only delivered orders have a payout`: REJECTED -> null; ACCEPTED -> null; state ' completed ' -> payout; amount undefined -> null; amount NaN -> null
- TC12 `test: summary adds delivered orders only`: [A completed 245 unsettled no finance, B completed 200 finance 16 settled, C rejected 100] -> { orders:2, gross:445, commission:40.5, net:404.5, settled:184, toBePaid:220.5, estimated:true }
- TC13 `test: summary of nothing is zero and not estimated`: [] -> all 0, estimated false
- TC14 `test: delivered order on time`: COMPLETED, creation '2026-10-09 19:38:00', accepted '19:39:00', ready '19:52:00', preparationTime 15, completed '20:10:00' -> keys [placed, accepted, ready, delivered], all done; accepted.detail 'Took 1 min to accept'; ready.detail 'Cooked in 13 min · on time', tone green; delivered tone green, at = parse(completed)

- TC17 `test: cancelled after accept`: CANCELLED, acceptedDate set, readyDate null -> keys [placed, accepted, cancelled]; cancelled at null, tone red
- TC18 `test: in progress shows what is still to come`: ACCEPTED with acceptedDate -> keys [placed, accepted, ready, delivered]; ready.done false, ready.at null, delivered.done false
