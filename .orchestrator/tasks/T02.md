# T02: API — custom date range and load-all-pages
Wave: 2 · Deps: T01 · Risk: med · Model: sonnet · Oracle: fail-before

## Goal
`getOrdersPage` can send a custom date range (`timeRange=CUSTOM&fromTime=…&toTime=…`) and reports `totalElements`;
a new `getAllOrders` loads every page of a filter (capped) for the Earnings tab.

## Context
Same backend contract as the PC dashboard (Vendor-Dashboard `src/apis/orderApi.ts:36-84`,
`src/utils/fetchAllOrderPages.ts`): GET /quickVerse/v2/order/{shopId}/orders, 50 orders per page, pages from 0,
`fromTime`/`toTime` only for CUSTOM, local 'YYYY-MM-DDTHH:mm:ss'. The backend is production and sensitive: pages are
fetched one after another, never in parallel, and never more than `maxPages`.

## Contracts
- Consumes: `TimeRange` with 'CUSTOM', `HistoryStatus`, `Order` (src/domain/order.ts); `mergeOrders` (src/domain/history.ts:4)
- Produces:
```ts
export interface OrdersFilter { statuses?: HistoryStatus[]; timeRange?: TimeRange; fromTime?: string; toTime?: string }
export interface OrdersPage { orders: Order[]; totalPages: number; totalElements?: number }
export const getOrdersPage: (shopId: string, f: OrdersFilter & { page: number }) => Promise<OrdersPage>;
export const getAllOrders: (shopId: string, f: OrdersFilter, maxPages?: number) => Promise<{ orders: Order[]; complete: boolean }>;
```

## Steps
1. Add `OrdersFilter`; change `getOrdersPage`'s second parameter type to `OrdersFilter & { page: number }`.
2. Build the query object in exactly this key order: `orderStatus` (statuses when non-empty, else undefined),
   `timeRange`, `fromTime` and `toTime` (only when `timeRange === 'CUSTOM'`, else undefined), `page`.
3. Add `totalElements` to the result: `Number(res.response.totalElements)` when it is a finite number, else omit it.
4. Add `getAllOrders(shopId, f, maxPages = 20)`: request page 0; total = max(1, totalPages); then pages 1..min(total,
   maxPages)−1 one at a time (await each); stop early on a page with zero orders; merge with `mergeOrders`;
   `complete = total <= maxPages`. Any failing page rejects the whole call with that page's error (no partial result).
5. Keep the existing comment style ("Contract copied from the web dashboard …").
