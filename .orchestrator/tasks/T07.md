# T07: Insights screen
Wave: 6 · Deps: T04 · Risk: low · Model: sonnet

## Goal
AC9: today's business numbers + live board counts, refresh on open and pull, error with retry.

## Read first
- `src/api/endpoints.ts` getDashboardStats, `src/domain/stats.ts`, `src/domain/format.ts`, `src/hooks/useRemote.ts`, `src/app/MainShell.tsx`

## Write-set
- create: src/screens/InsightsScreen.tsx
- modify: src/app/MainShell.tsx
- test: __tests__/insights.test.tsx

## Steps
1. Props `{ shopId, board, active }`; useRemote(() => getDashboardStats(shopId), [shopId, refreshKey]); bump refreshKey
   when `active` turns true; RefreshControl.
2. Layout: LargeHeader 'Today' + subtitle date ('Monday, 6 October'). Hero (no card chrome): caption 'Earnings today',
   display money(revenue) in ink, footnote 'From <n> orders'. Then Group 'Orders today' rows: 'Orders' n (receipt-text),
   'Completed' `${completionRate}%` (circle-check green), 'Avg time to accept' minutesLabel (timer), 'Avg cooking time'
   minutesLabel (chef-hat). Group 'Right now' rows from board: 'New' (bell, blue), 'Preparing' (chef-hat, amber),
   'Ready for pickup' (package-check, green) with counts. Footer text 'Updates when you open this tab or pull down.'
3. Error: EmptyState wifi-off with error + 'Try again'. Loading first time: ActivityIndicator.
4. MainShell: tab 'insights' → InsightsScreen with active = tab === 'insights'.

## Test cases
- TC1 stats {orders:5,revenue:1200,avgAcceptSec:30,avgPrepSec:600,completionRate:80} → shows '₹1,200', '80%', '30 sec', '10 min'.
- TC2 board with 2 PENDING → 'New' row value '2'.
- TC3 rejection → 'Try again' → getDashboardStats called twice.
