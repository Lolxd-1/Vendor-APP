# T07: Shell — Earnings tab, order details page, wiring
Wave: 7 · Deps: T04 T05 T06 · Risk: high · Model: opus · Oracle: fail-before

## Goal
The app has five tabs (Orders · History · Earnings · Insights · Account). Tapping an order in History or Earnings
opens the Order details page (no tab bar); Android back closes it; a newly arrived pending order still closes any page
and shows Orders > New exactly as today.

## Context
M1. `MainShell` owns navigation: tab + page stack, `backAction` (pure), the BackHandler and the safety rule "pending
count went up -> `setNav({ tab: 'orders', stack: [] })` and segment PENDING" (MainShell.tsx:67-76). That rule is the
reason the order page lives on this stack (a Modal would stay on top of Orders > New). The ringing itself is native and
must not be touched. High risk: navigation next to the new-order rule.

## Contracts
- Consumes: `HistoryScreen({ shopId, onOpenOrder })` (T05), `EarningsScreen({ shopId, active, onOpenOrder })` (T06), `OrderDetailsScreen({ order, onBack })` (T04)
- Produces: `export type TabKey = 'orders' | 'history' | 'earnings' | 'insights' | 'account'`;
  `export type PageKey = 'timings' | 'alerts' | 'order'`; `backAction` signature and behavior unchanged

## Steps
1. TabBar: insert `{ key: 'earnings', label: 'Earnings', icon: 'wallet' }` after History. Nothing else changes.
2. MainShell: extend the two types; add `const [openOrder, setOpenOrder] = useState<Order | null>(null)`;
   `showOrder = useCallback((o: Order) => { setOpenOrder(o); openPage('order'); }, [openPage])`.
3. Tabs map: `history: <HistoryScreen shopId={session.shopId} onOpenOrder={showOrder} />`,
   `earnings: <EarningsScreen shopId={session.shopId} active={nav.tab === 'earnings' && !page} onOpenOrder={showOrder} />`.
4. Pages: `page === 'order' && openOrder && <View style={styles.fill}><OrderDetailsScreen order={openOrder} onBack={closePage} /></View>`.
5. Leave the BackHandler, `backAction`, the pending-count effect, AppState handling and the Orders/Insights/Account
   wiring byte-identical.
