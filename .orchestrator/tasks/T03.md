## Steps
1. useRemote: on deps change / reload → loading=true, error=null, call load; an increasing request id discards stale
   results; unmount discards late results; error = ApiError.message else 'Something went wrong. Try again.';
   `load === null` → idle.
2. useStoreStatus: getSchedule(shopId) via useRemote; `status = storeStatus(schedule, now)` recomputed every 60 s;
   `setOnline(online)` → busy → setManualOffline(shopId, !online) → reload → true; failure → error
   'Could not change store status. Try again.' → false. `save(week)` → saveSchedule(shopId, week,
   schedule?.manualOffline ?? false) → reload → true; failure → 'Could not save store timings. Try again.' → false.
3. useShopProfile: first `shopDetails` with a non-empty name among board orders; else once per shopId
   getOrdersPage(shopId,{timeRange:'THIS_YEAR',page:0}) and take the first found; cache in a module-level Map by shopId;
   errors → null silently.

## Test cases
- TC1 useRemote: resolve → data, loading false; reject ApiError('X') → error 'X'; two loads, first resolves last → data is the second's.
- TC2 useStoreStatus: schedule {manualOffline:false, week:{}} → status.online true; setOnline(false) calls
  setManualOffline('7', true), returns true; rejection → false + error text above.
- TC3 save(week) passes current manualOffline (true when schedule says true).
- TC4 useShopProfile: board order with shopDetails {name:'Tasty'} → returned, getOrdersPage not called; empty board →
  getOrdersPage called once, returns orders[0].shopDetails.
