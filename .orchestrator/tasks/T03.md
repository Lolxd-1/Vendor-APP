# T03: Search field, range calendar, period sheet
Wave: 3 · Deps: T00 T01 · Risk: med · Model: sonnet · Oracle: fail-before

## Goal
Three reusable pieces for the History redesign: a search box, a month calendar that picks a day range (no future
days), and the "Show orders from" bottom sheet (presets + custom dates).

## Context
M1 History redesign. No date-picker library is allowed (no new dependencies), so the calendar is a plain 7-column
grid of Pressables. Period math lives in `src/domain/period.ts` (T01) — call it, never re-implement dates.
Design: blue/white, Apple-minimal; tokens in `src/ui/theme.ts`; all text through `Txt`.

## Steps
1. SearchField: a row (height 44, radius `radius.m`, surface background, hairline `colors.line` border, horizontal
   padding `space.m`) with `Icon search` (18, ink3), a `TextInput` (`flex: 1`, style `type.body` + `color: colors.ink`,
   `placeholderTextColor={colors.ink3}`, `accessibilityLabel={placeholder}`, `autoCorrect={false}`,
   `autoCapitalize="none"`, `returnKeyType="search"`, `onChangeText={onChange}`), and — only when `value !== ''` — a
   Pressable `accessibilityLabel="Clear search"` (hitSlop 8) with `Icon x` that calls `onChange('')`.
2. CalendarRange (Monday-first):
   - Shows one month, initially the month of `last ?? first ?? today`; header: Pressable `accessibilityLabel="Previous month"`
     (chevron-left), month title `Txt headline` 'October 2026', Pressable `accessibilityLabel="Next month"` (chevron-right),
     disabled (`accessibilityState.disabled`, 0.35 opacity) when the shown month is today's month.
   - Weekday row M T W T F S S (caption, ink3); day cells 1/7 of the width, height 44, Pressable with
     `accessibilityLabel` '14 October 2026' and `accessibilityState={{ selected, disabled }}`; days after `today` are
     disabled (ink3, no onPress effect); leading blanks before the 1st.
   - Tap rules: if `first === null` or both set -> `onPick(day, null)`; if only `first` is set: day ≥ first ->
     `onPick(first, day)`, day < first -> `onPick(day, null)`.
   - Look: first/last days = blue circle (36) with white text; days strictly between = blueSoft band; today = blue text.
3. PeriodSheet: `Sheet` titled 'Show orders from'. One radio row per PRESETS entry (`accessibilityRole="radio"`,
   `accessibilityState={{ checked: value.key === key }}`, `accessibilityLabel` = preset label, check icon when
   checked) -> `onChange(presetPeriod(key, now))` then `onClose()`. Then a 'Custom dates' radio row (checked when
   `value.key === 'CUSTOM'` or the calendar is open); tapping it opens the CalendarRange below the rows (local state
   first/last, starting from `value.range` when value is CUSTOM, else null/null) and a hint line: no first -> 'Pick the
   first day'; first only -> 'Pick the last day, or apply for one day'; both -> `rangeLabel(customPeriod(first, last).range)`.
   An 'Apply' `Button` (size l, disabled until first is set) -> `onChange(customPeriod(first, last ?? first))` then
   `onClose()`. Reset the calendar state when the sheet opens.
4. The sheet content must scroll if it is taller than the sheet (wrap it in a ScrollView).

## Test cases
Use `now = new Date(2026, 9, 14, 15, 30)` (Wed 14 Oct 2026).
- TC1 `test: picking a preset reports it and closes`: value presetPeriod('TODAY', now); press 'Yesterday' -> onChange called once with key 'YESTERDAY' and range.start = 13 Oct 00:00; onClose called
- TC2 `test: custom dates pick a first and last day`: press 'Custom dates', '6 October 2026', '9 October 2026', 'Apply' -> onChange with key 'CUSTOM', range [6 Oct, 10 Oct); onClose called
- TC3 `test: one tapped day applies as a single day`: 'Custom dates', '8 October 2026', 'Apply' -> range [8 Oct, 9 Oct)
- TC4 `test: days after today cannot be picked`: 'Custom dates'; the '15 October 2026' cell has accessibilityState.disabled true; pressing it then 'Apply' -> onChange not called (Apply still disabled)
- TC5 `test: tapping a day before the first restarts the range`: 'Custom dates', '9 October 2026', '6 October 2026', 'Apply' -> range [6 Oct, 7 Oct)
- TC6 `test: month arrows move the calendar and stop at this month`: 'Custom dates'; 'Next month' disabled; press 'Previous month' -> text contains 'September 2026'
- TC7 `test: the search field clears itself`: SearchField value 'abc' -> press 'Clear search' -> onChange('') ; value '' -> no 'Clear search' element
