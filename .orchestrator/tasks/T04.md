# T04: Order details page (timeline, bill, payout)
Wave: 4 · Deps: T00 T01 · Risk: med · Model: sonnet · Oracle: fail-before

## Goal
A full-screen Order details page, opened from History and Earnings: status, timeline with times and delays, the bill,
and what the shop earns (Zomato's order-wise payout "Details").

## Context
M1. MainShell (T07) will push this page; here it is a plain component with `order` and `onBack`. All rules come from
T01: `timelineOf(order)` and `payoutOf(order)`; formatting from `src/domain/format.ts`. Commission is the only
deduction; when it is an estimate the label must say so. Design: blue/white Apple-minimal, white cards (radius
`radius.l`, hairline border), `LargeHeader` with Back, 16 dp gutters, no shadows.

## Steps
1. `ScrollView` (bg `colors.bg`, bottom padding `space.xxl`) with `LargeHeader title={`Order #${order.orderId}`} onBack={onBack}`.
2. Status row: `StatusPill` from `historyStatusInfo(order.state)`; if `payoutOf(order)` is not null, a second pill:
   settled -> 'Settled' (green, icon badge-check), else 'To be paid' (amber, icon hourglass).
   Under it (footnote, ink2, 1 line each): `${dayTime(order.creationTime, Date.now())} · ${paymentLabel(order.paymentMethod)}`
   and the customer name when present.
3. Card "Timeline": for each Step a row: left a 12 dp dot (done: filled — green/red by tone, blue for neutral; not
   done: hollow, `colors.line` border) joined by a 2 dp vertical line to the next step; middle `Txt headline`
   (ink if done, ink3 if not) with the detail under it (footnote; red for tone red, green for tone green, ink2
   otherwise); right `clockTime(at)` (callout, tabular) only when `at` is not null.
4. Card "Bill": one line per item `${itemCount ?? 1} × ${name || 'Item'}` with `money(itemPrice × itemCount)` on the
   right when both are numbers; 'No items listed' when empty; then 'Items total' = `money(order.amountExcludingDeliveryFee)`
   (headline); 'Delivery fee (paid by customer)' when `deliveryFee` is a number; 'Customer paid' when `totalAmount` is a number.
5. Card "Your earnings": with a payout p: 'Gross revenue' `money(p.gross)`; `Commission (${p.pct}%)` or
   `Commission (${p.pct}%, estimated)` with `money(-p.commission)`; 'Net receivable' `money(p.net)` (headline, green);
   then a footnote 'Commission is the only deduction.'; when estimated also 'Estimated at 10% because QuickVerse did not
   send the commission for this order.' Without a payout: state REJECTED or CANCELLED -> 'No payout for this order';
   otherwise 'Payout after delivery'.
6. When `orderDescription` is non-empty: a card with icon message-square-text, caption 'Note from customer' and the text.
7. When `deliveryPartnerDetails.name` exists: a card with icon bike, the name, and when a mobile number exists a
   `Button label="Call" variant="secondary" size="s" icon="phone"` -> `Linking.openURL(`tel:${number}`)`.
8. Every label/value line: label `flex: 1, minWidth: 0` (numberOfLines 2 for item names), value `flexShrink: 0`,
   `tabular`. Section titles are `Txt callout` ink2 above each card (like `Group` titles in src/ui/List.tsx).
